### Growth and SEO brief
Read `docs/SEO_BRIEF.md` before any SEO or content work. It sets the audience, priorities, cadence, attribution links and pricing-claim rules, and it replaces the earlier daily SEO handoff.

### SEO changelog
Every PR that changes SEO content (titles, meta, H1, lead, FAQ, schema, internal links, canonicals, new pages) must add an entry to the top of `SEO_CHANGELOG.md` in the same PR, using the same fields as existing entries (date, PR link, page URLs, query, GSC numbers or "not recorded", what changed, blank Result line).
