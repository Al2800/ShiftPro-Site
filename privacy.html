Privacy Policy for ShiftPro

Last updated: 20 July 2026

ShiftPro helps individual shift workers plan schedules, track hours, estimate pay, and create reports. This policy describes the current iPhone and iPad release.

Data you provide

ShiftPro stores information you choose to enter, including profile details, shifts, work patterns, notes, workplace information, hourly rates, pay-period settings, and notification preferences. This data is stored locally in ShiftPro's app container. No account is required and the developer does not operate a server that receives this working data.

Optional Apple services

  • Calendar: EventKit is used only after permission to create or reconcile shift events.
  • Notifications: ShiftPro schedules local reminders only after you enable them.
  • StoreKit: Apple processes subscription transactions and provides verified entitlement status.
  • Face ID or Touch ID: iOS performs authentication. ShiftPro never receives biometric data.

Data we do not collect

The current release contains no advertising, third-party analytics, third-party crash reporting, or tracking SDK. It does not collect advertising identifiers, contacts, photos, health data, precise location, or Reminders data.

Security

Working data uses iOS device and file protection. App-lock settings and PINs use the iOS Keychain with device-only protection. Optional protected exports use password-based authenticated encryption.

Export and deletion

You can export supported data or use Delete All Data in Settings. Shared exports are governed by the receiving destination. Delete All Data removes ShiftPro model data, preferences, Keychain items, temporary exports, caches, and app-created Calendar data the app is permitted to remove.
